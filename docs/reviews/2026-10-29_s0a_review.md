## What changed

| Area | Finding | Resolution |
|---|---|---|
| Source of truth | Prompts written before the design documents claimed precedence over them | Order fixed: ADRs → `docs/design/` → `schemas/` → `prompts/`; prompts point to design and no longer restate it |
| Names | Author-track task cards used table/column names that differ from `data_model.md` | Cards and acceptance tests follow `data_model.md`; missing names were defined there |
| Ledger coverage | Values the S1 engine needs (kinetics, analyzer precision, QC failure and re-run, drift, probe drift, deadband, staffing, cadence) had no ledger id | 42 entries added (A077–A118); 12 found a source, the rest are labelled assumptions |
| Grades | Some values were graded more strongly than their sources allow (a cell-free pH offset, a vendor bead study, range ends not seen in a source) | Regraded (S → P or A); observed values kept separate from applied ones; `range_grade` where a range end is unsourced |
| Claims | The public research summary described neat-sample viability as falling; the source's authors state it did not | Rewritten; the simulator applies 0 for neat samples, a non-zero slope is a diluent scenario |
| Checks | The public-number check ignored the research summary and did not follow assumption ids to their sources; the Stop check missed edits made from the shell and did not run tests | Gate extended (with transitive A → S check); change detection by repository state; tests included; a `--manual` gate mode |
| Experiment design | S2 gates required the context-preserving preset to win on every seed | Gates are structural (forced-error fixtures with hand-typed outcomes); stochastic comparisons are reported with intervals, never gated |
| Flags | Two flags claimed the same timestamp | `two_clocks` owns the separate sampling and measurement times; `write_time_keys` owns key immutability |
| As-of | An author SQL task could read result versions published after the decision time | As-of now covers result versions (`available_at`) and historian rows (`ingested_at`) |
| Definitions | Holding time was defined three ways | `hold_time` = run start − sampling; `turnaround` = availability − sampling; defined once in `data_model.md` |
| Guard | Two publishing command forms passed the shell guard | Blocked and tested |
